# kory-mockup

Visual reference for the KORY website redesign (Spanish-language mockup, 25 pages).

- Purpose: reference for rebuilding sections in Shopify (Liquid). This is not production code and is not meant to be deployed as is.
- How to view: open `pages/index.html` in a browser. Paths are relative.
- Blue highlights mark content that is still unconfirmed ("por confirmar" / "propuesta"). Prices and names are drafts.
- Phase 1 (proposed): the three kit pages, the two Christmas bundles (`navidad.html`) and the welcome coupon. Everything else is later.
- Shopify keeps cart, checkout, coupons and orders. Only the visual sections are meant to be reused.
- Private repository. Please do not share the link or the content outside the team.

## Folders

| Folder / file | Content |
|---|---|
| `pages/` | The 25 full pages. Start with `pages/index.html`. |
| `sections/` | The same pages split into one HTML file per section (hero, cards, FAQ, footer...). Index in `sections/README.md`, shared rules in `sections/base.css`. |
| `assets/` | Images and the logo. |
| `docs/` | English design spec (`KORY_Design_Spec_EN.docx`) and the screen PDF (`KORY_Mockup_Screens_EN.pdf`, 30 pages). |
| `ASSETS_AND_LINKS.md` | Fonts, colors, image list and link targets (Shopify URLs still to be defined). |
